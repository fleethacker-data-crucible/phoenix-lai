## Fixed in this pass

### Speed
1. **Exact-token reply reuse** (`Engine.ReplyIds`). A reply was re-encoded from its text for the next request; BPE gives
   different tokens than the model sampled, so the prompt cache broke right there and every follow-up re-read the whole
   reply. Now replies are templated with the sampled tokens. Code check on a 1,069-token reply: **7.6 s → 2.1 s**
   (98 new + 2,258 cached tokens). Every next message in a chat benefits the same way.
2. **Gemma load 2× faster** (`GemmaGpu.UploadBlocks`). Weight repacking was single-threaded byte copies (~0.4 GB/s);
   now parallel rows with block copies. **14.9 s → 7.9 s**, accuracy identical.
3. (earlier today) code-check prompt reuses the reference sections already in the conversation: ~1,900 → ~100 new
   tokens; Gemma check **10.5 s → 1–3 s**.

### Memory / context
4. **Gemma sliding-window ring** 1,536 → 512 slack slots: **−0.31 GB VRAM** (fixed cache 0.78 → 0.47 GB), i.e. ~20K
   more Gemma context when VRAM is the limit. Safe because of fix 1 (long rewinds are now rare); correctness proven
   bit-exact.
5. Page file: diagnosed that Windows *commit*, not VRAM, capped context (AMD driver charges VRAM to commit). With the
   16–32 GB page file Gemma gets 32K automatically and other programs no longer fail to start.
6. (earlier) 8 / 4-bit KV cache for Llama (q8 default: same answers at half the memory), auto context from free VRAM +
   commit, RAM released after GPU upload.

### Security
7. **Indirect code execution through file writes** — closed. The model could write `.git/hooks/pre-commit` (git runs
   it on the next commit) or `.vscode/tasks.json` (VS Code can run it on folder open). Writes into `.git`, `.vscode`,
   `.idea`, `desktop.ini`, `.gitattributes`, `.gitmodules` are now refused by `ShellGuard.CheckWrite`.
8. **`<script>` inside written HTML was refused as a "command"** and triggered an extra model round. Command tags are
   now only looked for outside file contents and code blocks.
9. **OpenAI API accepted `Origin: null`** — any downloaded HTML file opened in a browser could drive the model. Refused.
10. Verified still holding: Host / Origin checks on both servers (DNS rebinding), `html\` path containment, project
    jail (absolute paths, `..`, junctions), `.llm-backup` read-only, shell-name scan in `run.ps1`, single guarded
    `Process.Start`.

### Reliability
11. Gemma returned **empty replies** (its native `<|tool_call>` token as the first token): those control tokens are now
    never sampled.
12. Gemma **announcing actions without the tag** ("First, let me check index.html.") ended the turn: one automatic
    nudge now continues it (verified: nudge → read → 3 files written → check green).
13. Stuck "Generating code…" spinner, null-element error in the status row, prompt row vanishing while replying.

### Code health
14. Removed dead GPU kernels (`MatVecChunked` + helper, `Kernels.QuantizeQ8`, `MatMulQ4Q8Unrolled`): −132 lines.
